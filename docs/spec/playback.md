# Playback and evidence v1

The [shared playback records](../../crates/pt-contracts/src/playback.rs) and [TypeScript mirror](../../packages/contracts/src/types.ts) define one schema-v1 player format: manifest/entries, registered cards, scene instances, per-fact reveals, complete snapshots/lights, authored timeline, measured read-along, shell/profile and acceptance evidence. Both apps use the same player. Audience loading accepts only fully verified immutable releases; explicit diagnostic loading remains a studio/developer operation.

Every depicted fact needs hash-bound image scope, primary acoustic and independent acoustic evidence. A nullable reveal bound means ineligible. Anchor terminal IDs identify one source-word occurrence, not a repeated string. Independent bounds may differ by at most 36,000 final-domain samples (0.75 seconds); use the later end. Missing, stale, uncertain or ambiguous required evidence cannot authorize a reveal. Filter contributors, their pixels and shadows on every evaluation, including darkness and backward seeks. Broad alignment coverage alone supplies no missing fact permission.

Original prose remains complete and ordered. Source spans use Unicode scalars. Word annotations retain measured points; `point-following-same-boundary-v1` groups a point only with the following measured positive interval at the identical start. Groups remain atomic. Read-along shows the active two-to-three-line chunk only; its text exception does not authorize upcoming imagery or music. One 48 kHz stereo PCM16 WAV master and one sampled media playhead drive all authored state and text. Sample mappings retain resampling, trims and gaps explicitly.

Title hold/dismiss minimums are 72,000/24,000 samples. Opening/closing curtains last 72,000 samples. Introductory narration may establish context with curtains closed; first-picture contributors must be eligible before curtain opening. Scene fades last 48,000 samples each with exactly 96,000 dark samples between swap and fade-in. Formal scene transitions contain no narration. Closing and terminal state fit within the master. User pause animates the INTERMISSION sign on UI time, down/up 1.2/0.8 seconds.

Supported actions are enter, exit, move, permitted face, rigid nod/shrug/recoil/bow/wobble, bounded perspective camera and complete lighting targets. Pose/hop/dynamic attachment, unsupported cameras and director-authored curtain/transition controls fail. Registered native aspect, pivots, crop transforms, supports and canonical dimensions are preserved. A character has one immutable book-local sprite; scene instances reuse it.

Profile `paper-player-r186-v1` is selected and unverified. The [fixture profile](../../fixtures/shared/two-scene-v1/profile.json) freezes the selected constants for diagnostic integration; schematic tests do not certify browser/device acceptance. Runtime/declaration pins are both 0.186.0. Use separate narrative-stage and house-lighting passes, sRGB assets/output, linear working target, PCFShadowMap, fixed geometry and resource bounds (DPR ≤1.5, images ≤4096, graphics/master each ≤256 MiB). All production profile changes require a new shared revision and affected acceptance reruns. Old-version receipts retain their actual identity.
