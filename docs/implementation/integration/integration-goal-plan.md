## Dependencies and cadence

Critical order: **INT-01 → INT-02 + early INT-07 → INT-03/04/05 → INT-06 → completed INT-08 → INT-09/10**. Develop the ledger, release instructions and integrated rejection/replay harness alongside the verifier families.

- **Server:** frozen R19 source; bounded HTTPS/config proposal; durable issuance/raw/accounting context; trusted review policy; current publication migration and recovery adapter.
- **Generation:** frozen G25 source; actual vendor codecs/examples; complete source/interval/map inventories; authentic review requests/results targeting actual media and captures.
- **Player/Studio:** stable source/dependency/profile and capture/load/mount handoffs; current browser/viewport proof; actual-Mac measurements remain separate from headless checks.
- At each completed item, read owner queues, publish the smallest usable shared handoff, and update only integration's evidence/dependency tables. After two failed approaches or 45 minutes, record an exact reproducer/owner request and advance independent work. Do not spawn additional agents.
